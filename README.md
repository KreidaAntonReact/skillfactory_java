## 1. Запуск проекта

Для запуска проекта нужено выполнить следующие.

### 1.2 Соберите проект:

```bash
./gradlew clean build
```

### 1.3 Запустите программу:

```bash
java -cp build/classes/java/main ru.skillfactory.Main
```

Или можете запустить проект через интерфейс IDEA.
