## 1. Запуск проекта

Для запуска проекта нужено выполнить следующие.

### 1.2 Соберите проект:

```bash
./gradlew clean build
```

### 1.3 Запустите программу:

```bash
java -cp build/classes/java/main ru.skillfactory.Main
```

Или можете запустить проект через интерфейс IDEA.

## 2. Выполненые задания:

### 2.1 Сервис по получению метеорологических данных

После запуска проекта программа запрашивает у пользователя широту и долготу, проверяет корректность введённых координат и выполняет запрос к API Яндекс Погоды. Дополнительно можно указать параметр `limit` — количество суток, за которые нужно получить прогноз.

В результате программа выводит полную информацию о погоде, текущую температуру из поля `fact.temp`, а также среднюю температуру по прогнозу. Средняя температура вычисляется по значениям `forecasts[*].parts.day.temp_avg` за указанное количество суток.
